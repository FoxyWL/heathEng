# Hearth

Менеджер игровых серверов для Windows 10/11 с публичным адресом для друзей без белого IP и проброса портов. Один и тот же туннель открывает любой локальный порт (TCP, UDP, HTTP).

Три части:

- **агент** (`hearth.exe`) запускается на вашем ПК: управляет серверами и показывает панель в собственном окне.
- **Rust-ядро** (`hearth-core.exe`) работает рядом с агентом: считает CPU и память серверов и следит за процессами. Если файла нет, Hearth продолжает работать на запасном режиме Node.
- **релей** (`relay/relay.js`) запускается на любом VPS с белым IP. Через него друзья попадают на ваш ПК.

## Установка

**Установщик (рекомендуется).** Запустите `Hearth-Setup-1.3.1.exe`. Права администратора не нужны: Hearth ставится в `%LOCALAPPDATA%\Programs\Hearth`, данные лежат в `%APPDATA%\Hearth`. Создаются ярлыки в меню «Пуск» и на рабочем столе, запись в «Установка и удаление программ». Тихая установка: `Hearth-Setup-1.3.1.exe /S`, удаление: `Uninstall.exe /S`.

**Без установки.** Положите `hearth.exe` в отдельную папку и запустите. Данные будут в папке `data` рядом с exe.

**Из исходников.** Нужен Node.js 20+: `node main.js` (или `npm start`). Зависимостей для запуска нет.

Windows может показать предупреждение SmartScreen: программа не подписана сертификатом. Нажмите «Подробнее» → «Выполнить в любом случае».

Окно Hearth открывается как приложение (Edge, Chrome, Yandex Browser или Brave в режиме приложения, без вкладок). Если подходящего браузера нет, панель откроется в браузере по умолчанию. Свой браузер: переменная `HEARTH_BROWSER` (путь к exe). Журнал работы: `hearth.log` в папке данных. При ошибке запуска Hearth показывает окно с причиной.

**Закрытие.** Закрыли окно, серверы не запущены: Hearth завершается сам. Серверы работают: Hearth спросит, оставить ли его в фоне. Полностью выйти: «Выйти из Hearth» в панели (серверы остановятся корректно). Повторный запуск открывает окно уже работающего экземпляра.

## Что умеет

**Игры.** Каталог из 26 вариантов: Minecraft (Vanilla, Paper, Folia, Purpur, Fabric), Terraria, Counter-Strike 1.6 / CZ / 2, Day of Defeat, Team Fortress 2, Garry's Mod, Left 4 Dead 2, Sven Co-op, Rust, ARK, Palworld, Valheim и другие. Файлы серверов Steam-игр скачивает SteamCMD (анонимный вход) с прогрессом. Поиск и фильтры по жанрам в каталоге.

**Selfhost для любой игры.** «Свой сервер»: команда запуска и список портов (TCP и UDP, через запятую). «Любой сервер Steam»: достаточно AppID, файла запуска и портов. Готовый сервер подключается как есть по пути к папке, ничего не копируется.

**Мощности ПК.** Раздел «Мощности»: выберите, какую часть компьютера отдать серверам. Три пресета (25%, 50% и 100% процессора, памяти и свободного места на диске) и ручная настройка ползунками. Hearth соблюдает бюджет: серверы привязываются к ядрам из выделенного набора (нулевое ядро остаётся системе), получают сниженный приоритет, сервер сверх бюджета памяти не запускается, новый сервер сверх бюджета диска не создаётся. У каждого сервера свой лимит памяти и число ядер, есть автораспределение и необязательный строгий режим (остановка сервера, который сильно превысил память). Живая загрузка показана против бюджета.

**Сеть и имена.** Раздел «Сеть»: адреса вашего ПК и для каждого короткое имя вида `sajiba-feleesee.hearth` (IP и имя однозначно переводятся друг в друга, есть защита от опечаток). Имя можно вставить обратно и получить IP. **Своё имя сервера:** вместо автоимени можно задать своё, например `soskacraft` (станет `soskacraft.hearth`) или с портом `soskacraft:25570` (порт сервера меняется сам, нужен перезапуск). Имена уникальны, занятые имена и порты отклоняются. Любые другие зоны (`soskacraft.mc:25570`) — бета для администратора (сейчас им считается владелец этого ПК), включается переключателем на странице «Сеть»; настоящие зоны вроде `.com` запрещены, чтобы не перекрыть сайты. Имя и порт видны в карточке сервера («В вашей сети»), для имени есть кнопки «Включить имя на этом ПК» и «Строка для hosts друга». В карточке сервера появляется строка «В вашей сети» с `имя:порт` и `IP:порт`. Для каждого сервера Hearth проверяет, что порт отвечает на адресе ПК (а не только на 127.0.0.1), подсказывает, что поправить, и открывает порты в брандмауэре Windows (запрос прав администратора, правила «Hearth: …») или закрывает их. Кнопка «Включить имя на этом ПК» добавляет строку в `hosts`. Важно: `.hearth` не настоящий домен интернета, это кодировка адреса. Имя откроется там, где его знают (ПК с записью в `hosts`), у остальных работает IP. Друзьям из интернета нужен публичный адрес туннеля, особенно за CGNAT.

**Поддержание сети и сервера.** Hearth следит за сетью, пока работает: если IP ПК сменился (например, роутер выдал новый адрес), он предупреждает, помечает имена в `hosts` как устаревшие и подсказывает, что обновить; если ПК потерял сеть или запущенный сервер перестал отвечать на адресе в сети (слушает только 127.0.0.1 или порт закрыт), в консоли сервера и в панели появляется предупреждение, а когда доступ вернётся, сообщение об этом. Для каждого имени видно, включено ли оно на этом ПК (`hosts`), а для сервера, открыты ли порты в брандмауэре Windows. Настройка «Запускать Hearth при входе в Windows» (в «Настройках», только в установленной версии) стартует Hearth без окна и поднимает серверы с включённым автозапуском, так что после перезагрузки ПК серверы возвращаются сами.

**Каталоги модов.** Для Minecraft поиск и установка из Modrinth прямо в Hearth и кнопка «Открыть Modrinth». Для каждой из 26 игр во вкладке «Каталоги» собраны популярные площадки: Hangar и SpigotMC, Steam Workshop, Nexus Mods, Thunderstore, uMod, SourceMod, AMX Mod X, CounterStrikeSharp и другие. Ссылки открываются в браузере по умолчанию; открыть можно только адреса из этого списка.

**Гайд.** Короткий гайд из шести шагов (игра, мощности, запуск, друзья, моды, бэкапы): кнопка «Гайд» на экране приветствия и в «Мощностях», команда в палитре `Ctrl+K`.

**Управление.**
- Обзор всех серверов карточками: состояние, игроки, память, быстрый запуск и остановка, публичный адрес.
- Страница сервера: живые CPU, RAM, игроки и аптайм с мини-графиками.
- Консоль: подсветка ошибок, поиск, «только проблемы», история (↑/↓), подсказки команд по Tab (для Minecraft с русскими названиями предметов), быстрые команды.
- Игроки (Minecraft): кто онлайн, белый список, операторы, баны, выгнать.
- Плагины и моды: список установленных (включить, выключить, удалить) и **онлайн-поиск по Modrinth** с установкой в один клик и проверкой контрольной суммы.
- Мир (Minecraft): размеры, бэкап, сброс.
- Запуск: память, порты, параметры Java и сервера, итоговая командная строка.
- Файлы: менеджер и редактор с подсветкой. Расписание: бэкапы с ротацией, перезапуск, команды по cron.
- Автоперезапуск при падении (до 5 раз за 10 минут).
- Палитра команд `Ctrl+K` (в том числе «Мощности: отдать 25 / 50 / 100% ПК»), новый сервер `Ctrl+N`, сворачивание панели `Ctrl+B`.

**Туннели.** У сервера может быть несколько публичных адресов (например, игровой порт и порт запроса Steam), каждый включается отдельно. Для каждого туннеля видны трафик в реальном времени, подключения, события и задержка до релея. Любой порт можно открыть вручную, включать и выключать без удаления.

**ИИ-помощник (необязательно).** По умолчанию выключен и ничего не отправляет. Если включить и указать свой ключ Anthropic, фрагмент журнала уходит в Claude API только после нажатия «Объяснить ошибки».

Русский и английский интерфейс, светлая и тёмная темы.

## Релей (на VPS)

```
RELAY_TOKEN=секрет RELAY_DOMAIN=tun.example.com PUBLIC_HOST=tun.example.com \
PORT_MIN=20000 PORT_MAX=20100 node relay/relay.js
```

Или через Docker: `docker build -f relay/Dockerfile -t hearth-relay .`

Откройте в firewall: `7000/tcp` (управление), `8080/tcp` (HTTP-туннели), диапазон `PORT_MIN–PORT_MAX` по `tcp` и `udp`. Для HTTP-туннелей нужна wildcard-запись DNS `*.tun.example.com` на IP VPS.

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `RELAY_TOKEN` | генерируется и печатается | общий секрет клиента и релея |
| `RELAY_DOMAIN` | `localhost` | базовый домен для HTTP-поддоменов |
| `PUBLIC_HOST` | = `RELAY_DOMAIN` | что показывать как адрес TCP/UDP |
| `CONTROL_PORT` | 7000 | порт управления |
| `HTTP_PORT` | 8080 | порт HTTP-туннелей |
| `PORT_MIN` / `PORT_MAX` | 20000 / 29999 | диапазон публичных портов |
| `MAX_TUNNELS` | 16 | туннелей на одного клиента |
| `HTTPS_PORT`, `TLS_CERT`, `TLS_KEY` | выкл. | HTTPS на стороне релея |

В панели откройте «Туннели» → «Настройки релея», введите адрес, порт и токен, включите. После этого у сервера («Настройки» → «Публичный адрес») и у любого порта появится адрес для друзей.

Релей сам сертификаты не выпускает. Для HTTPS нужен wildcard-сертификат на `*.tun.example.com` и переменные `HTTPS_PORT`, `TLS_CERT`, `TLS_KEY`, либо Caddy или nginx перед релеем.

## Безопасность

- Панель слушает только `127.0.0.1`, требует токен и отклоняет запросы с чужим именем хоста. Не выставляйте её наружу.
- Токен релея даёт право открывать порты на вашем VPS: задайте длинное значение.
- Ключ Anthropic хранится открытым текстом в `config.json` в папке данных.
- Файлы плагинов проверяются по SHA-1 из каталога Modrinth, имя файла очищается от путей.

## Структура проекта

```
main.js              точка входа (окно, обработка ошибок, выход)
agent/server.js      HTTP API панели, события SSE, туннели серверов
agent/lib/           procman (процессы), catalog + gamedefs (игры), steamcmd, modrinth,
                     tunnel (клиент), core (Rust-ядро), scheduler, files, java, store,
                     capacity (бюджет мощностей), sources (каталоги модов), netname + netaccess
                     (имена .hearth, доступ по сети, брандмауэр), appwindow, winutil, applog
relay/               релей для VPS
shared/              общий протокол туннеля
core/                Rust-ядро (std-only): статистика процессов и системы
web/index.html       страница; web/css/ стили; web/highlight.js подсветка файлов
web/js/              модули панели: boot, events, shell, servers, server, capacity, network, guide, sources, gameicons, console, players,
                     plugins, world, launch, settings-tab, files, schedule, tunnels,
                     newserver, palette, charts, icons, lib, state
installer/           скрипт установщика NSIS
scripts/             сборка, значок, подготовка exe, пересборка импортов web/js
test/                тесты
```

Игры добавляются записью в `agent/lib/gamedefs.js` (Steam) или `agent/lib/catalog.js`: поля настроек, порты, команда запуска, регулярное выражение «сервер готов». После добавления функций в `web/js` выполните `npm run imports`.

## Сборка

```
npm install
npm run build:core    # Rust-ядро (нужен cargo; для Windows с Linux ещё mingw-w64)
npm run build         # значок → exe без консоли → установщик (если есть makensis)
```

Результат в `dist/`: `hearth.exe` и `Hearth-Setup-<версия>.exe`. Сборка идёт с `--no-bytecode`: байт-код V8 привязан к платформе сборки, а exe для Windows собирается и на Linux.

## Известные ограничения

- Реальные серверы загрузки в среде разработки недоступны, поэтому загрузка проверена на имитациях. Форматы ответов Mojang, Adoptium и Modrinth сверены с живыми API, PaperMC (Fill v3), Purpur, Steam и terraria.org сверить не удалось. AppID и параметры запуска игр собраны по документации разработчиков; если у игры изменится формат, правится соответствующая запись в `agent/lib/gamedefs.js`.
- Сборка проверена под Wine (установка, запуск, удаление, Rust-ядро), но не на самой Windows. Окна сообщений об ошибках (через PowerShell) под Wine не проверялись.
- Установщик не подписан: SmartScreen предупредит при первом запуске.
- Управление игроками, мир и плагины-файлы доступны для Minecraft; плагины онлайн ищутся для Paper, Purpur, Folia и Fabric.
- Мощности: ограничение сделано привязкой к ядрам и приоритетом, а не жёстким потолком процента CPU. Память Java ограничивает `-Xmx`, у остальных игр она контролируется наблюдателем (предупреждение и, если включено, остановка). Привязка к ядрам проверена на Linux на настоящих процессах; на Windows она идёт через PowerShell и на самой Windows не проверялась. Встроенное в Rust-ядро применение маски (команда `limit`) проверено на Linux; готовый `hearth-core.exe` в сборке прежний, чтобы использовать новую команду, пересоберите ядро для Windows (`npm run build:core`).
- Сеть: проверка доступности идёт с самого ПК по его адресу и не видит блокировку брандмауэра (на Windows поэтому показывается наличие правила «Hearth: …»). Автозапуск с Windows и правила брандмауэра на самой Windows не проверялись. Правила брандмауэра и запись в `hosts` собираются и проверены тестами как команды, но выполнение с правами администратора на самой Windows не проверялось. Имя `.hearth` не работает у других ПК без записи в `hosts`.
- Один клиент на один релей, токен общий.
- Для UDP-туннеля сессия живёт, пока идут пакеты (таймаут 60 с).
- Бэкап и распаковка используют системный `tar` (есть в Windows 10 1803+).
